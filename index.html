04 / ALÉM DO SOFTWARE

Software e hardware no mesmo projeto.

O BusPass vai além da interface web: combina leitura RFID, comunicação via ESP32, controle com Arduino e um terminal desenvolvido com impressão 3D. Um projeto que conecta software, API e eletrônica embarcada.

ESP32ArduinoRFID RC522TFT / LCDJava + Spring BootMySQLImpressão 3D

Protótipo em testes. A integração entre leitor, API, processamento da passagem e display está sendo validada. Trata-se de uma demonstração acadêmica, não de um sistema comercial.

06 / DÚVIDAS FREQUENTES

Transparência
faz parte da viagem.

O BusPass é um projeto tecnológico em desenvolvimento. Aqui está o que você precisa saber sobre o estágio atual.

O BusPass já funciona como aplicativo oficial de ônibus?+

Não. É um projeto de demonstração e desenvolvimento da equipe Four Sync, sem vínculo declarado com operadoras de transporte ou prefeitura.

As recargas usam dinheiro real e Pix?+

O projeto permite gerenciar créditos registrados no sistema. A integração com meios de pagamento bancários reais não está confirmada como implementada.

Os horários e ônibus são acompanhados por GPS ao vivo?+

Não anunciamos rastreamento GPS em tempo real como funcionalidade validada. As consultas se baseiam nos dados disponíveis no sistema.

A catraca RFID já está pronta para uso?+

A leitura RFID e a comunicação com ESP32 fazem parte do protótipo. A validação completa da integração física ainda está em desenvolvimento.
